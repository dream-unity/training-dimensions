# Dimensional Reasoning Framework

## Purpose

Training Dimensions converts a conventional mind map into a constrained reasoning laboratory. Complexity is not measured by node count. Each level introduces a qualitatively different operation that must be visible in the map.

## Representational grammar

### Nodes

Nodes name what exists in the model: a phenomenon, state, factor, trajectory, rule, framework, observer, model, architecture, adaptive system or invented axis.

### Lines

Lines state how two nodes relate. A line should carry a meaningful verb such as `shapes`, `is constrained by`, `feeds back into`, `would differ if`, `is generated by the assumption`, or `appears differently to`.

### Ghost branches

A ghost branch is a temporary prompt attached to the selected node. It asks the learner to perform the active dimensional operation. On completion, the prompt is replaced by the learner’s node and semantic relationship.

## Level criteria

### 1D — Focus

Success requires a usable definition, a boundary, a present-state description and an evidence anchor. No branch is required. This is retained because precise isolation is a genuine prerequisite, even though it is intentionally not relational.

### 2D — Relation

The learner creates direct pairwise connections and names each relationship precisely.

### 3D — System

The map must contain interacting factors and cross-links. A radial list is not sufficient.

### 4D — Transformation

The learner maps prior state, transition, next state, delay and feedback. Merely adding dates to an unchanged network is insufficient; the relationships themselves must transform.

### 5D — Trajectory space

The learner holds several plausible evolving histories together, identifies branch conditions, convergence and irreversible thresholds.

### 6D — Generative rules

The learner identifies assumptions, operating rules, prohibitions, permissions and objective functions that generate the available trajectories.

### 7D — Framework plurality

The learner compares coherent rule-generating frameworks, translates concepts between them and states incompatibilities or higher integrations.

### 8D — Observer relativity

Observer, standpoint and scale become model variables. The learner tracks blind spots and how observation changes the observed system.

### 9D — Model evolution

Models themselves update, compete, self-protect, merge or disappear. The learner identifies selection pressure and invariants across revisions.

### 10D — Architecture design

The learner redesigns objectives, feedback loops, constraints, interfaces and governance while stating trade-offs.

### 11D — Co-evolving architectures

Several adaptive architectures alter one another’s incentives, models and future redesigns. The learner maps emergence and meta-stability.

### 12D — Dimension invention

The learner creates a new representational axis, identifies what it reveals, identifies what it hides and specifies evidence that would force revision of the axis itself.

## Training logic

A selected dimension is a dedicated mode, not a ceiling. The learner enters that dimensional operation directly. Each mode has its own coaching sequence, spatial scaffold, ghost-branch placement, semantic line grammar, common-failure warning and completion rubric. A 6D map therefore trains generative-rule reasoning immediately rather than forcing the learner through an identical lower-level interface. The completion score measures structural fidelity to the chosen grammar, not intelligence.

The front-page field guide teaches every mode before launch through a worked personal-development example, required map shape, step sequence, failure case and pass test.

## Evaluation direction

Future evaluation should test transfer rather than self-report alone. Candidate measures include:

- improved causal discrimination;
- richer yet calibrated counterfactual generation;
- detection of feedback and delayed consequences;
- identification of hidden objective functions;
- ability to translate between frameworks without collapsing differences;
- better intervention selection under uncertainty;
- willingness and accuracy when revising models.
